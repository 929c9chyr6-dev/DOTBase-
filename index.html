Aktivita uživatelů

Online = aplikaci právě aktivně používá · Standby = aplikace je otevřená, ale neaktivní nebo na pozadí · Offline = bez heartbeat déle než 3 minuty.

🧩 Správa modulů

Nastav, co běžní uživatelé vidí v hlavním menu a které moduly jsou pro ně skutečně dostupné. Admin má přístup vždy.
Jak to funguje
Zobrazit v menu pouze skryje nebo ukáže kartu na hlavní obrazovce. Online / Offline určuje skutečnou dostupnost modulu pro běžné uživatele. Offline modul nelze obejít přímým odkazem; u modulů s vlastními API akcemi je blokace vynucená i serverem.
